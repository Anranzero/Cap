# cap

免费、离线、无广告的 Windows 截图、截图批注、MP4 / GIF 录制工具。C# + .NET 8 + WPF，免安装，普通用户权限运行。

## 运行

本机开发时使用桌面“cap 开发预览”：保存 C#、XAML 或图标资源后会自动编译并重开预览窗口，不需要反复发布 EXE。窗口标题含“开发预览”和刷新编号。预览截图快捷键为 Ctrl+Shift+F10，录屏为 Ctrl+Shift+F11，GIF 为 Ctrl+Shift+F12；设置与输出隔离于 `.artifacts/dev-preview`。关闭预览窗口后，再次双击该入口可重开；录制或批注未完成时先结束操作，再保存源码，避免自动重启打断操作。

桌面“cap 测试版”打开已打包程序的设置页，标题显示运行版本；它不会随源码自动刷新。已有旧版进程时，需要先在旧版“设置 → 退出程序”退出。

双击 `dist/cap.exe`。正常启动仅显示系统托盘图标，不弹出主窗口。若托盘图标被 Windows 收起，请展开右下角隐藏图标区域。

| 操作 | 默认快捷键 |
| --- | --- |
| 截图 | Ctrl + Alt + A |
| MP4 录制 / 停止 | Ctrl + Alt + V |
| GIF 录制 / 停止 | Ctrl + Alt + G |
| 截图 / 选区取消 | Esc |
| 确认功能 / 批注完成后复制 | Enter |
| 直接复制所选截图 | Ctrl + C |
| 保存截图 | Ctrl + S |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Y 或 Ctrl + Shift + Z |
| 移动截图选区（进入批注后） | 方向键，Shift + 方向键每次 10 px |

托盘右键提供“截屏、录制、设置、退出”。录屏模式框选后，选区变为粉色并在下方显示“开始录制”面板（可选 MP4/GIF、鼠标设置）；GIF 使用独立快捷键，或从“设置 → 录制 → 窗口 / 全屏录制”主动选择格式及目标。设置底部也可彻底退出，设置的“录制”页可恢复中断录制。双击托盘图标进入选区。快捷键被占用时会提示，可在设置中更换。已有实例运行时再次启动会明确提示先退出，避免新版启动后无反馈。设置标题显示当前运行版本。

也可执行 `cap.exe --settings` 直接显示设置窗口。`--startup` 用于自启动，不显示就绪提示。

修改快捷键时，点击对应输入框并直接按组合键，无需填写键名；Esc 撤回本次录入，点击“保存设置”生效。录入本程序已有的快捷键时只更新输入框，不执行截图或录制；与其他功能重复时立即在该输入框下方提示，并保留原有效快捷键。被其他程序占用的组合仍会在保存时提示。

深色 / 浅色主题选中后立即生效并自动保存，不必关闭窗口；其他设置仍通过“保存设置”提交。

## 截图与批注

按快捷键后冻结桌面，先拖动自由框选；未框选时功能条停在鼠标所在显示器的顶部居中（与飞书一致），框选后移到选区上方并显示“截图、滚动截图、录屏、提取文字”，截图模式同时在下方显示批注工具栏，可直接标记，不需要再次点击“截图”。只有点击复制、保存或其他功能才执行操作，不自动开始录制。鼠标悬停窗口可自动识别，单击选中窗口。选区支持拖动和八方向缩放，支持跨显示器框选。方向键移动选区，Alt+左右键切换功能，Enter 完成当前功能，Esc 取消；靠近屏幕边缘时工具条会移到可见位置并避免相互重叠。

悬浮工具栏提供矩形、椭圆、箭头、直线、画笔、文字、序号、马赛克、模糊，以及撤销、重做。颜色和粗细收在色点旁的下拉菜单中，选择绘图工具不会自动展开第二排。马赛克和模糊对已经画好的内容也生效。导出使用原始物理像素。撤销最多保留 80 次操作及约 128 MB 历史，较早操作会合并进底图。

选择“复制完成”写入剪贴板；“保存”支持 PNG / JPG；“钉住”显示可拖动的置顶贴图。贴图支持滚轮缩放、双击恢复大小、右键复制/关闭和 Esc 关闭。

### 滚动截图与提取文字

点击“滚动截图”不退出截图界面：选区变为实时画面，原功能栏位置显示一行可拖动浮条。直接向下滚动鼠标滚轮即可截取，画面停稳后自动拼接；也可点击向下箭头自动滚动，再点暂停停止自动滚动。点击勾号完成并打开结果预览；叉号或 Esc 退出滚动并回到截图选区，可继续标记、复制或保存，此时再按 Esc 才退出截图。还没框选就先点“滚动截图”，随后框出的区域会自动进入滚动截取；选区小于 64 × 80 像素时提示重新框选。支持 PNG/JPG 保存及复制。仅支持向下滚动；自动滚动不受目标窗口支持时可继续手动滚轮。重复背景、动画、固定底栏或重叠不足时会拒绝拼接并保留当前结果。上限为 4000 万像素 / 30000 像素高度。

选择“提取文字”后，使用 Windows 已安装 OCR 模型在本地直接识别当前选区，并将识别文字复制到剪贴板，只显示简短完成提示，不再打开结果窗口。多行文字保留换行；未识别到文字时提示重新框选，不清空剪贴板。剪贴板短暂占用时自动重试，持续失败会明确提示未复制。没有可用模型时明确提示，不联网下载模型；不保证任意语言、旋转或模糊文字的识别率。

## MP4 / GIF

1. 从托盘或快捷键框选区域，在功能条点击“录屏”，直接开始录制当前选区，不再弹出设置窗口；截图批注工具栏的录屏图标使用同一流程。
2. 默认录制 MP4；由 GIF 快捷键进入时直接录制 GIF。帧率、GIF 宽度、鼠标指针、点击高亮、坐标方式、字号和颜色沿用已保存的设置。
3. 浮动控制条可移动、暂停、继续、停止；再次按录制快捷键也可停止。停止后显示“正在保存…”并保留录制时长，等待保存完成。
4. 需要窗口、显示器、全桌面目标或临时参数时，主动进入“设置 → 录制 → 窗口 / 全屏录制”。选择“已选区域”时，在确认参数后框选；取消任一步都不会开始录制。
5. 录制结束自动保存并打开预览；MP4 支持播放与进度定位，可保存或复制录制文件到剪贴板。右键可打开所在目录。

MP4 支持 15 / 24 / 30 / 60 FPS，使用 Windows 自带 Media Foundation H.264 编码器。GIF 支持 1–60 FPS（可在设置中自定义），支持最大宽度缩放；宽度 0 表示原始尺寸，不放大。保持原始宽高比；MP4 宽高调整为偶数。

指针使用系统实际光标形状及热点，点击显示短暂扩散高亮。坐标标签随指针移动，支持屏幕绝对坐标/录制区域相对坐标、字号与自定义颜色。设置页和录制配置中的颜色按钮可直接点选常用色；展开“更多颜色”后通过红、绿、蓝滑杆预览并确认任意颜色，无需填写颜色代码。所有叠加均在编码前绘制，保存的视频/GIF 含有相同内容。坐标字号按录制原始物理像素计算，缩小输出时会一起缩小。

GIF 使用 RGB332 全局调色板、稳定位置抖动、LZW 压缩、重复帧合并及变化矩形编码；只在内存中保留少数帧。GIF 本身最多 256 色，照片/渐变仍可能存在色差；追求原画颜色请选 MP4。GIF 延时单位为 10 ms，24/30/60 FPS 使用累计时间取整避免持续漂移；部分播放器会自行限制极短延时。

这版录制不含声音（当前需求未要求音频）。没有网络上传、更新检查、账号或订阅。

## 设置与自启动

设置保存于 `%LOCALAPPDATA%\cap\settings.json`，保存前保留上一版 `.bak`。配置损坏时提示并使用默认值，保留原文件。日志在 `%LOCALAPPDATA%\cap\logs`，自动限制单文件大小。

默认输出到当前用户“图片”目录下的 `cap`，可更改。支持浅色/深色主题。关闭设置窗口默认回到托盘；取消“关闭窗口时最小化到托盘”后关闭设置窗口会退出程序。

自启动只写入当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `cap` 值，不需要管理员权限，关闭开关即移除。请从最终 `cap.exe` 启用。移动 EXE 后先运行新位置的 EXE 并重新开启自启动；开启自启动的后续启动也会刷新路径。退出 cap 不会撤销用户主动开启的自启动。

## 捕获方式与系统限制

- 支持 Windows 10 **2004（19041）及以上**、Windows 11，x64。采用 PerMonitorV2 DPI 感知，统一以物理像素处理边界和负坐标。
- 录制优先 WGC（Windows Graphics Capture），单显示器 MP4 区域和指定窗口使用 D3D11；跨显示器区域、不可用的 WGC 自动回退 GDI。局部 GIF 使用 GDI 直接捕获选区，并以细边框标出实际区域，避免 WGC 的整显示器黄框产生误导；完整单显示器 GIF 仍优先 WGC。即时冻结截图使用 GDI，避免等待首帧。
- WGC 窗口录制跟随窗口移动，固定初始画布大小；窗口变大裁剪，变小补黑。窗口关闭后结束录制并保存已捕获帧。GDI 回退捕获初始桌面矩形，可能包含遮挡窗口，也不会跟随窗口移动；控制条会显示实际后端。
- WGC 保留 Windows 的系统捕获边框。受保护视频、UAC 安全桌面、锁屏、独占全屏及部分远程桌面由 Windows 限制；无法绕过。HDR 使用 BGRA8，未增加 HDR 色调映射。
- Windows N 缺少 Media Foundation 时需要用户安装微软 Media Feature Pack，程序会明确报错。普通 Windows 10/11 不需要另装 .NET 或 FFmpeg。
- 控制条和贴图使用 Windows 捕获排除接口。高帧率、高分辨率及动态内容受 CPU/GPU/磁盘速度限制；跟不上时延长上一帧、跳过过期采样并显示计数，不无限积压。
- self-contained 包含 .NET/WPF 运行库，EXE 体积主要来自运行时。默认不压缩程序集，以降低空闲内存；本机测量私有内存约 60 MiB，EXE 约 179 MiB。可用 `build.ps1 -Compact` 生成约 75 MiB 的压缩版，本机对应私有内存约 131 MiB。这些短时测量不代表所有电脑。首次启动系统会将原生运行库解包到用户缓存目录，无安装器、无管理员权限。程序本身不访问网络；首次构建还原 Windows SDK / 运行时引用包需要网络。

## 异常恢复

录制期间在目标文件旁写入 `*.capjournal`，逐帧无损 Deflate 压缩、包含时间戳和提交标记，约每秒刷盘。正常完成后删除日志，发布最终 `.mp4` / `.gif`；编码中的文件使用 `.partial.mp4` / `.partial.gif` 后缀。

异常退出后进入“设置 → 录制 → 恢复中断的录制”，读取当前保存目录的日志，重新编码完整提交的帧。恢复会生成新文件，不覆盖原录制或日志。最后未完成的记录可丢弃；断电时最后约一秒数据可能尚未落盘。无法保证磁盘或日志损坏时恢复。恢复确认后可手动清理旧日志/partial 文件。

恢复日志占用额外磁盘及压缩 CPU；高分辨率动态画面可能增长很快，长录制请预留足够空间。可用磁盘低于 256 MB 时停止并保留恢复日志，避免一直写满磁盘。

## 开发与构建

需要 Windows x64 和 .NET 8 SDK（`global.json` 使用 8.0.426）。没有额外第三方生产包，也没有 FFmpeg 许可证/分发依赖。

```powershell
# 编译整个解决方案、执行自动化测试、生成 dist/cap.exe
.\build.ps1

# 开发预览：保存代码后自动编译并重启，不发布 dist/cap.exe
.\dev.ps1

# 指定 SDK 路径
.\build.ps1 -Dotnet 'C:\path\to\dotnet.exe'

# 更小的压缩 EXE（空闲内存通常更高）
.\build.ps1 -Compact

# 直接构建与发布
dotnet build cap.sln -c Release -warnaserror
dotnet publish src/Cap.App/Cap.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

本次开发 SDK 安装在 `%LOCALAPPDATA%\cap-dev\dotnet`；`build.ps1` 优先发现该路径，之后回退 PATH 上的 dotnet。SDK 是开发工具，不随 EXE 分发。WPF 不支持安全裁剪，因此没有启用 PublishTrimmed / NativeAOT。

```text
src/Cap.App         托盘协调、设置/录制/预览 WPF 窗口
src/Cap.Core        像素坐标、捕获与录制契约
src/Cap.Capture     WGC/D3D11、GDI、显示器与窗口识别
src/Cap.Annotation  框选、批注、滤镜、历史与贴图
src/Cap.Recording   帧调度、鼠标叠加、MP4/GIF、恢复日志
src/Cap.System      设置、全局快捷键、自启动、日志（命名空间 Cap.Platform）
tests/             无第三方测试框架的可执行断言/集成测试
docs/              设计、模块报告、测试与验收记录
dist/cap.exe       最终独立程序
```

# 发布程序自身进行真实截图、MP4/GIF 录制及暂停冒烟测试

本机实际验证与未覆盖场景见 [docs/verification.md](docs/verification.md)。多显示器混合 DPI、负坐标实体屏幕、HDR、设备丢失和数小时稳定性需要对应硬件继续验收，不能仅由单屏测试推断为通过。
