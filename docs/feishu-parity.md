# 飞书截图功能逆向规格（cap 复刻依据）

本文记录对本机飞书客户端（`D:\Feishu`，Electron `147.0.7727.149`）截图功能的实测结果，
作为 cap 截图/批注界面复刻的依据。所有数值均来自 2560×1440 物理分辨率、
Windows 显示缩放 150% 环境下的屏幕实测（物理像素 ÷ 1.5 = WPF 逻辑像素）。

## 1. 观测方法

| 手段 | 说明 |
| --- | --- |
| 全局快捷键触发 | 发送 `Ctrl+Shift+A`（飞书默认截图热键）后抓屏 |
| 窗口枚举 | 浮层为 Electron 透明全屏窗口，类名 `Chrome_WidgetWin_0`，尺寸 2561×1440 |
| 像素分析 | 按表面色/图标亮色聚类，定位工具条 bbox 与每个图标中心 |
| UI Automation | 读取模式条与取色面板的无障碍文案，拿到精确矩形 |
| 交互录屏 | 拖选、点选工具、切模式、点按钮，逐步抓屏对照 |

证据截图保存在 `.artifacts/feishu/shots/`（`tip3`、`tools`、`iconprobe`、`round2`、`modes`、`mode-ui` 等子目录）。

## 2. 模式条（未选区时）

- 默认位于**屏幕顶部水平居中**（实测矩形 974,6 → 613×69 物理像素，中心 x=1280）；可拖动。
- 深色圆角条（`#1A1A1A` 附近），高约 46dp，圆角 9dp；左侧 6 点拖动手柄。
- 四个模式页签（物理矩形，y=18 高 45）：`截图` 91×45 @x1037、`滚动截图` 145×45 @x1148、
  `录屏` 91×45 @x1313、`提取文字` 145×45 @x1424。
- 激活项为白色圆角矩形 + 黑字，其余白字；切换模式只改变高亮，模式专属界面在**框选之后**出现。

## 3. 选区

- 选区边框：亮蓝 1px（约 `#2F7CFF`～`#4C88FF`），8 个圆形把手，左上角 `宽 × 高` 尺寸标签。
- 未拖选时，鼠标悬停窗口 → 窗口四周亮蓝 1px 高亮 + 尺寸标签（窗口自动识别）。
- 放大镜：约 217×256 物理像素（145×171dp），1px 灰边框，内容为光标附近像素放大，
  中心有约 8×8 像素白框标记当前取样点。

## 3.5 取色器（随光标）

截图浮层在光标附近常驻一个取色面板，实测：

| 项 | 物理 | 逻辑 |
| --- | --- | --- |
| 面板整体 | 217×256 | 145×171 |
| 放大区 | 217×180 | 145×120 |
| 内容 | 放大像素 + 居中白框标记 + 被放大的选区蓝边 |  |
| 读数区 | 深色底（约 `#1A1A1A`）+ 白色 13dp 文案 |  |

四行文案（UI Automation 实测原文）：

1. `坐标: <屏幕X>,<屏幕Y>`
2. 色块 + `RGB:<r>,<g>,<b>`
3. `按 Ctrl + C 复制色值`
4. `按 Shift 切换 RGB/HEX`

行为：`Shift` 在 RGB/HEX 之间切换（HEX 形如 `#131315`）；`Ctrl+C` 复制当前格式的色值；
面板相对光标位于**左上偏下**（光标右下为面板），贴边时自动翻转，避免超出屏幕。

## 7. cap 复刻状态

已对齐（本轮新增粗体）：

- 工具条「主行 + 上下文参数行」两排结构；表面 `#292929`、图标 `#E8E8E8`、激活 `#3A4355`、
  40dp 高、10dp 圆角、拖动柄、细/中/粗、7 色板（选中白环 + 对勾）、字号下拉、效果滑杆。
- **取色器**：放大镜 + 坐标/RGB 读数 + `Ctrl+C` 复制色值 + `Shift` 切换 RGB/HEX，
  面板 145×171dp、放大区 145×120dp、中心白框标记、贴边翻转。
- **滚动截图改为显式开始**：框选后显示 `▶ 开始滚动截图` ｜ `ⓘ 帮助` 胶囊，点击才开始滚动；
  帮助按钮展开内嵌说明面板。
- **模式条默认位置改为屏幕顶部居中**（与飞书一致），仍可拖动。
- 保存图标改为飞书式向下箭头；默认墨色为色板红 `#F05B56`。
- **工具栏新增复制按钮**（飞书位置：裁剪之后、撤销之前）。
- **录屏模式选区与开始面板**：粉色选区边框 `#DB5EA4`；`开始录制`（`#3370EB`）+ MP4/GIF 单选 +
  设备行（扬声器/麦克风/摄像头以删除线标注 cap 不支持，鼠标设置可用）；面板位于选区底部居中。

本轮新增对齐：

- **提取文字改为浮层内嵌面板**（`TextExtractPanel`）：标题「提取文字」+ 右上 ✕ + 提示行 + 可滚动识别文本，
  280×350dp、`#1A1A1A`、圆角 6dp；按 `Esc` 先关面板回到选区，`Ctrl+C` 复制识别文本。
  已用开发者预览实拍验证（框选后再次点击「提取文字」执行）。
- **工具栏新增裁剪入口**（飞书 ✂ 位置：特效工具之后、撤销之前）：
  点击后切到选区控制点并提示「拖动选区控制点调整裁剪范围，Enter 完成」。

本轮新增对齐：

- **窗口收缩式二次裁剪**：点 `✂` 后浮层**收缩到选区尺寸并移动到选区位置**（实测飞书行为），
  裁剪阶段隐藏功能条、保留选区把手与尺寸标签；确认后输出裁剪后的图像。
  已实拍验证：`Cap 截图` 窗口由 2560×1440 收缩为 600×360 @ (700,300)。
- UI 测试套件首次完整通过（含裁剪断言）。

本轮新增对齐：

- **`///` 标注（高亮笔）工具**：工具条新增「标注」按钮（飞书位置：模糊之后、裁剪之前），
  拖动绘制半透明笔画；参数条与飞书一致：`不透明度 [滑杆] 30 %` + 七色调色板，默认 30%。
  注：飞书该工具在本机多次实测均未渲染出可见笔画（疑似版本/环境限制），cap 依其参数条语义实现。

## 8. 最终差距（仅剩刻意排除项）

- **翻译**（`(A)↻` + 目标语言下拉，24 种语言）：依赖飞书云端服务，cap 为离线工具，**刻意不复刻**。
- 复制后飞书浮层短暂显示「保存到剪贴板」浮标；cap 复制后直接关闭浮层（行为等价、提示形式不同）。
- 录屏模式：cap 支持 MP4/GIF 与鼠标高亮，飞书另有扬声器/麦克风/摄像头选项（cap 明确标注不支持）。
