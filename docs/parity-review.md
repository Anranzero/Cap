## 7. 刻意不复刻

| 项 | 原因 |
| --- | --- |
| 翻译（`(A)↻` + 24 语言下拉） | 依赖飞书云端翻译服务；cap 为离线工具，无可用后端 |
| 录屏设备行（扬声器/麦克风/摄像头） | 需要音频与摄像头采集链路（WASAPI/Media Foundation 音轨封装），当前录制为纯屏幕视频 |
| HDR / 混合 DPI 副屏 / 数小时稳定性 | 需要对应硬件验收，当前环境无法覆盖 |

## 8. 本轮已补（提交见 git log）

- Rust：工具顺序修正（标注移到模糊之后）、形状行当前色圆点、马赛克/模糊「模糊强度」、标注「不透明度」滑杆并驱动透明度、色板选中对勾、取色器 RGB 行色块。
- 两套：录制结果/预览窗口显示时强制前台（避免点任务栏只弹设置窗口）；录制控制条按工作区定位（不再压任务栏、全屏贴底居中）；热键失败托盘可见 + 一键重试。
- 录制性能：60fps 掉帧从 80.8% 降到 2.0%（鼠标移动场景），详见 `docs/verification.md`。

## 9. 仍待补齐（可实现）

1. **标注工具语义**：飞书是「文本标注」——点开后输入 ≤16 字符文本，带半透明底色和不透明度滑杆；当前两套实现为自由高亮笔画。这是唯一的功能语义偏差。
2. **复制后的「保存到剪贴板」浮标**（两套都缺）。
3. **Rust 字号下拉**（12/16/20/24/32pt）替代小/中/大按钮。
4. **Rust 马赛克/模糊的 3 类型按钮**（马赛克/模糊/块状）与 3 形状按钮。
5. **OCR「编辑」内联可编辑**（两套都以复制替代）。
6. Rust 悬停窗口的独立尺寸标签（飞书在悬停窗口时显示窗口尺寸）。
