# 2026-10-28

## 滚动截图改为“不退出截图”的原地模式

用户反馈：点击“滚动截图”会退出截图界面；正确流程是点击后若已选区域直接进入滚动（自动滚动 + 手动滚轮），未选区域则先框选再滚动。

### 实现要点
- `ScreenshotWorkflow.RunAsync` / `SelectRegionAsync`：`ShowDialog` 改为 `Show()` + `TaskCompletionSource`，覆盖层不再占用模态消息循环，滚动浮条可作为其子窗口正常交互（App 的 `ShutdownMode=OnExplicitShutdown`，非模态安全）。
- `ScreenshotWindow`：新增 `scrolling` 状态机（`EnterScrollingMode` / `ExitScrollingMode` / `StartArmedScrolling`）。
  - 进入滚动时用 `SetWindowRgn` 在覆盖层上按选区（外扩 2px）挖洞：页面实时可见、真实滚轮直达页面、`WindowFromPoint` 也能取到目标窗口；退出时用 `SetWindowRgn(handle, 0, true)` 清除。
  - 滚动会话仍是原 `ScrollingCaptureWindow`（`Owner` 指向覆盖层、`hosted` 时不再提示“点击选区”），完成后由 `ScreenshotResult.ScrollImage` 交给 App 打开 `ImageResultWindow`。
  - 叉号/Esc 只退出滚动并回到截图选区（`modeBar` 复位为“截图”），再按 Esc 才退出截图。
- `CaptureModeBar` 改为无选区也显示（否则“先选再滚”无法触发），无选区时停在鼠标所在显示器工作区右下角（新增 `NativeDesktop.WorkAreaAt`）。
- `EditorSurface` 在滚动模式下不再绘制选区边框/控制点/尺寸标签，由 `ScrollingCaptureOutline` 描边。
- README 更新截图与滚动截图两段说明。

### 构建环境（重要）
- 本机原本无 .NET SDK；已下载 SDK **8.0.426** 并解压到 `%LOCALAPPDATA%\cap-dev\dotnet`，`build.ps1` / `dev.ps1` 会自动优先使用该路径。
- 网络：直连 TLS 失败（schannel），但环境有 HTTP 代理 `127.0.0.1:59706`；curl 走代理仍握手失败，**PowerShell `Invoke-WebRequest` 可用**。`WebClient` 与 `Add-Type` 被沙箱拦截。
- 桌面快捷方式：`WScript.Shell`/COM 在 PowerShell 中被拦截，改用 Python + ctypes 调 `IShellLinkW`/`IPersistFile` 创建后删除临时脚本。
- 已验证：`dotnet build cap.sln -c Release -warnaserror` → 0 警告 0 错误；6 个测试工程全部 PASS（含滚动 22 条断言）；已 publish 单文件 `dist\cap.exe`（约 180 MB）；桌面 `cap 测试版.lnk` → `dist\cap.exe`。
